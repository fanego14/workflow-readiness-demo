# Business Workflow Assessment — Portfolio Demonstration

I developed the original workflow after identifying a recurring business problem through my professional experience: organizations often need help turning operational information into clear, actionable next steps to limit business-related exposures.

The project was designed to ideate what it would look like to develop a lead-generator for prospective-customer conversations by collecting structured information and producing a personalized report. I defined the requirements, configured the code and connected services, tested the workflow from intake through report delivery, and debugged integration issues using GPT and Claude throughout development.

This repository contains a sanitized demonstration of the document-generation component. It uses fictional information and excludes the original business identity, proprietary assessment methodology, and production configuration. The broader workflow connected Tally, Make, a Railway-hosted API, and Postmark; those external configurations are not included here.

The original workflow completed end-to-end testing before implementation was paused. It is not currently presented as a live production service. This example demonstrates my approach to business requirements, workflow integration, troubleshooting, and customer-facing output.
